# Koltugun Kumanda Yutma Itirafnamesi

**T.C. Minder Adaleti Genel Mudurlugu**  
**Uzaktan Kumanda Kayip ve Iade Dairesi**  
**Dosya No:** KMD-2026-0917-KOLTUK

Bu depo, evin salonundaki koltugun yillardir yuttugu uzaktan kumandalari resmi olarak itiraf etmesi icin yazilmis ulusal protokoldur. Koltuk suclu degildir; koltuk sadece acktir. Kumanda ise tuzludur.

## Ne Yapar?

Calistirinca:

1. Koltuk resmi kimligini aciklar.
2. Yuttugu kumanda sayisini (bilimsel olmayan ama resmi duran bir formulle) hesaplar.
3. Bir itirafname, bir iade vaadi ve bir "bir daha yemem" taahhutnamesi basar.
4. Isterseniz kumandayi ararsiniz. Bulamazsiniz. Bu da protokolun parcasidir.

## Kurulum

```bash
python3 itirafname.py
```

Baska bir sey gerekmez. Python 3 yeter. Koltuk da yeter.

## Ornek Cikti

Program her calistirmada farkli bir resmi evrak uretir. Ciktiyi yazdirip koltugun altina koyabilirsiniz. Koltuk okumaz ama dosya acilir.

## Yasal Uyari

Bu yazilim:

- Kumandayi fiziksel olarak geri getirmez.
- Minderi ameliyat etmez.
- Televizyonu acmaz.
- Siyasi parti, sendika veya cips markasi degildir.

Sadece itiraf eder.

## Katki

Pull request atmadan once lutfen evinizdeki koltuga danisin. Minder onaylamazsa PR reddedilir.
